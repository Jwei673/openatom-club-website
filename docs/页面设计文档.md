# 电子科技大学成都学院开放原子开源社团官网系统页面设计文档

版本：v0.1  
项目类型：社团官网 + 内容社区 + 后台管理系统  
前端技术栈：Vue 3 + TypeScript + Vite  
设计基准：比赛第一名作品 Organization-Blog  
文档状态：初始设计版，可后续调整  

---

## 1. 页面设计目标

本项目的前端设计不从零开始，而是以比赛第一名作品 `Organization-Blog` 为视觉基础进行正式化、工程化和功能扩展。

第一名作品已经具备较好的前台视觉基础，包括：

```text
大图 Hero 首屏
简洁顶部导航
蓝色科技感主色
明亮留白布局
卡片式信息展示
滚动动效
明暗主题切换
多页面结构
中英文切换
```

正式官网需要在保留这些优点的基础上，扩展为支持登录、权限、内容社区、后台管理、活动报名、项目管理等功能的完整系统。

设计目标如下：

```text
1. 保留第一名作品的大气、清爽、科技感风格
2. 首页继续保持品牌展示属性，不堆积后台功能
3. 页面结构从静态展示升级为数据驱动
4. 前台、社区、后台三类页面分层设计
5. 保证 PC 端和移动端适配
6. 保证后续内容持续增加后页面不杂乱
7. 形成统一设计系统，方便 Vue 组件化开发
```

## 2. 设计基准来源

本项目参考的前端作品为：

```text
https://github.com/Memsetqwq/Organization-Blog
```

该项目 README 中说明，其页面包括首页、社团简介、新闻列表、新闻详情、导航站、登录页和管理后台等页面；其技术栈为 Parcel、原生 JavaScript、CSS 变量主题系统、IntersectionObserver 滚动动画和 localStorage 模拟数据库。

该项目的首页结构包括：

```text
Hero
社团介绍
技术方向
近期动态
核心团队
开源项目
```

正式官网应参考该视觉和结构，但不能继续使用 localStorage 模拟正式数据，应接入真实后端和数据库。

## 3. 整体设计定位

官网整体视觉定位为：

```text
高校技术组织官网
+ 开源社区门户
+ 青年科技社团形象展示
```

设计关键词：

```text
开放
开源
科技
校园
清爽
可信
年轻
专业
```

页面应避免：

```text
过度花哨
过度后台化
信息堆积
颜色杂乱
动效过多
首页过长且没有重点
```

最终效果应接近：

```text
对外：大气、正式、有社团品牌感
对内：清晰、可用、有社区互动感
后台：稳定、高效、权限清楚
```

## 6. 首页设计

首页是官网最重要的页面，必须保持大气、简洁、品牌感强。

首页结构建议如下：

```text
1. 顶部导航栏
2. Hero 首屏
3. 社团数据 / 社团概览
4. 技术方向
5. 近期动态
6. 核心团队
7. 开源项目
8. 加入我们 / 页脚
```

这与第一名作品截图中的结构基本一致，但正式系统需要把静态数据改为后端数据。


---

### 19.2 字体层级

建议：

```text
Hero 标题：40px - 56px
页面主标题：32px - 40px
区块标题：28px - 32px
卡片标题：18px - 22px
正文：14px - 16px
辅助文字：12px - 14px
```

### 19.3 圆角与阴影

建议：

```text

```

---

### 19.4 动效

保留第一名作品的轻量滚动动画思路。

要求：

```text
页面滚动时模块淡入 / 上移
卡片 hover 轻微上浮
按钮 hover 轻微变亮
主题切换平滑过渡
避免大面积复杂动画
尊重 prefers-reduced-motion
```

## 24. Codex 前端开发要求

给 Codex 开发前端时必须强调：

```text
1. 以前端比赛第一名作品 Organization-Blog 为视觉基准
2. 不要从零随意设计首页
3. Vue 版本必须使用 Vue 3
4. 页面必须组件化
5. 首页不要塞后台功能
6. mock 数据阶段不要急着接后端
7. 后续逐步替换为接口数据
8. 移动端必须适配
9. 统一抽象 Button、Card、Header、Footer 等组件
10. 不能破坏原作品的清爽科技感
```

## 25. 页面设计总结

本系统页面设计的核心原则是：

```text
首页做品牌
列表页做内容
详情页做阅读
个人中心做参与
后台做管理
```

第一名作品已经提供了较好的前台视觉基础。正式官网应保留其：

```text
校园大图 Hero
蓝色科技感
留白布局
卡片展示
滚动动效
明暗主题
多页面结构
```

同时需要补足：

```text
真实登录
真实后端数据
成员社区
权限后台
活动报名
项目管理
内容审核
通知与日志
```

一句话总结：

```text
前台继承第一名作品的视觉气质，后台按照正式管理系统设计，所有复杂功能通过分层页面承载，不堆到首页。
```
